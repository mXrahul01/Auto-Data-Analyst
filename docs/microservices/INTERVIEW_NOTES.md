# Interview preparation

Current honest description: added a microservices foundation with independently packaged Python APIs, typed JSON contracts, a React status workspace, Docker orchestration, and CI checks. Data analysis and training are planned capabilities, not completed claims.

Explain these choices:
- A monorepo keeps contracts and review manageable while containers preserve service boundaries.
- Separate service dependencies avoid forcing every container to install the scientific stack.
- Immutable version IDs will connect profiling, recipes, charts, and experiments reproducibly.
- Celery task transport does not itself guarantee reliable domain events.
- Health is process liveness; readiness must eventually check actual required dependencies.
- Cross-validation must fit preprocessing within each fold to prevent data leakage.

Update resume bullets only after implementation evidence exists. Do not claim supported scale, accuracy, users, or production reliability from this scaffold.
